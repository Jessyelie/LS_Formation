                        L'avantage du fichier d'installation .msi que vous avez téléchargé, c'est qu'il est conçu pour être déployé en masse très facilement. Voici les grandes étapes pour réaliser cela :
                        1. Préparer le dossier partagé
                            L'Active Directory a besoin que le fichier d'installation soit accessible par tous les ordinateurs du réseau.
                            • Créez un dossier partagé sur votre serveur (ex: \\MonServeurAD\Deploy\).
                            • Placez-y le fichier GLPI-Agent-1.21-x64.msi.
                            • Assurez-vous que le groupe "Ordinateurs du domaine" a le droit de lire ce dossier.
                        2. Créer le fichier de configuration de l'Agent (Le fichier MST)
                            Puisque l'installation se fera en arrière-plan sans interface graphique, il faut pré-configurer l'adresse de votre serveur GLPI. Pour cela, on utilise un petit fichier de transformation (un fichier .mst) qui accompagne le .msi.
                            • Vous pouvez générer ce fichier facilement avec un outil gratuit comme Orca (de Microsoft) ou utiliser un générateur en ligne officiel de GLPI.
                            • Dans ce fichier, vous enregistrez le paramètre de votre serveur (ex: SERVER="http://192.168.1").
                        3. Créer la GPO dans Active Directory
                            • Sur votre serveur AD, ouvrez la console Gestion des stratégies de groupe (gpmc.msc).
                            • Faites un clic droit sur votre domaine ou sur l'Unité d'Organisation (OU) contenant vos ordinateurs, et choisissez "Créer un objet GPO...". Nommez-le par exemple Déploiement GLPI Agent.
                            • Faites un clic droit sur cette nouvelle GPO et cliquez sur Modifier.
                            • Dans la fenêtre qui s'ouvre, naviguez jusqu'à (Configuration ordinateur / Stratégies / Paramètres logiciels / Installation de logiciel.)
                            • Faites un clic droit dans la zone vide > Nouveau > Paquet.
                            • Sélectionnez le fichier .msi en passant impérativement par le chemin réseau (ex: \\MonServeurAD\Deploy\GLPI-Agent-1.21-x64.msi).
                            • Choisissez le mode de déploiement Avancé.
                            • Dans l'onglet Modifications, cliquez sur Ajouter et sélectionnez votre fichier .mst configuré à l'étape 2.
