+configuer le routeur (NB: les port doivent etre de nivaeu 3 entre 2 routeur :: ajouter les plaquette WIC-1ENET)
    >Configuration de l'adresse IP du routeur
        •enable
        •configure terminal
        •interface <nom de l'interface>
        •ip address <adresse ip du meme sous resau que les port des 2 PC et tout autre apareil> <masque de sous-réseau>
        •no shutdown
        •exit
    >Configuration de la route 
        -->routage statique
            • ip route <réseau_visé> <masque_du_réseau> <adresse_du_prochain_routeur>

        -->routage dynamique (a faire dans chaue router)
            •configure terminal
            •router rip
            •version 2
            •network 192.126.1.0 (ex de resau qui passe par r1 vers r2 pas les addresses ip eux-meme )
            •network 192.126.2.0 (ex de resau qui passe par r1 vers r2 pas les addresses ip eux-meme )
            •network 10.10.1.0   (ex de resau  qui lie directememt r1 et r2 )
            •exit
